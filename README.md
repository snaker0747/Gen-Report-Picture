# ระบบจัดทำรายงานภาพ (Photo Report Generator)

ระบบเว็บแอปพลิเคชันสำหรับจัดทำรายงานภาพถ่ายและเอกสารรายงานภาพ สามารถส่งออกไฟล์เป็น PDF, Word (.docx) และ JPEG (.zip) ได้อย่างสะดวกรวดเร็ว

## คุณสมบัติเด่น
- 🚀 **ทำงานบน Client-Side 100%**: รวดเร็ว ปลอดภัย รูปภาพไม่ถูกส่งออกนอกเครื่อง
- 📄 **รองรับขนาดกระดาษหลากหลาย**: A4, A3, F4, Letter ทั้งแนวตั้งและแนวนอน
- 🖼️ **ปรับแต่งภาพอิสระ**: ซูม เลื่อนภาพ ปรับอัตราส่วนภาพในแต่ละช่องได้
- ⬇️ **ส่งออกได้หลายรูปแบบ**:
  - เอกสาร PDF คุณภาพสูง (jsPDF)
  - เอกสาร Microsoft Word (.docx) จัดเลย์เอาต์ตารางเรียบร้อย (docx.js)
  - รูปภาพแยกหน้าไฟล์ JPEG บีบอัดเป็น .zip (JSZip)
- 🔤 **รองรับภาษาไทยสมบูรณ์แบบ**: ใช้ฟอนต์ Sarabun / TH Sarabun New

## การติดตั้งและการใช้งาน
เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้ หรือเปิดผ่าน Vercel URL
